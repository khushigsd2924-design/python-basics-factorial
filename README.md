# Factorial Calculator

A simple Python program that calculates the **factorial of a given number**. This project demonstrates basic Python programming concepts such as user input, arithmetic operations, loops, and conditional logic.

## 📌 Project Description

This project contains a Python script, `factorial.py`, that takes a number as input and calculates its factorial.

The factorial of a non-negative integer `n` is represented as `n!` and is calculated as:

```text
n! = n × (n-1) × (n-2) × ... × 1
```

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## ✨ Features

* Calculates the factorial of a number
* Simple and beginner-friendly Python implementation
* Takes input directly from the user
* Displays the calculated factorial
* Uses only standard Python functionality
* No external libraries required

